Free market data, as plain JSON

Perpetual funding, open interest and Fear & Greed — refreshed by our bot roughly every 30 minutes. No API key. No signup. No tracking. Use it in your own tool, bot, sheet or dashboard.

ENDPOINTS
FileWhat you get
api/radar.jsonFunding % per 8h, signed annualised APR, open interest in USD millions, optional mark price + Fear & Greed

Base URL: this site’s root. Example: https://<your-app-host>/api/radar.json

Fetch from the browser 
fetch("api/radar.json")
  .then(r => r.json())
  .then(d => {
    const fg = d.fear_greed;
    const hot = d.funding
      .filter(x => Math.abs(x.funding_pct_8h) > 0.02)
      .slice(0, 3);
    console.log(fg.value, hot);
  });
Send it to a Telegram chat 
import json, urllib.request
d = json.load(urllib.request.urlopen(
  "https://YOUR-HOST/api/radar.json"))
top = d["funding"][:3]
text = "\\n".join(
  f'{x["symbol"]}: {x["funding_pct_8h"]:+.3f}%/8h'
  for x in top)
# send `text` via your bot API
Field notes: apr_pct keeps the sign of the funding rate — negative means shorts pay longs (a short-side carry, not a “negative yield”). mark_price is omitted when the source does not provide it rather than being sent as null. oi_usd_m is 0 for fallback sources that publish funding only.

Rules of the road

۳) اگر عمومی منتشر می‌کنی، منبع را ذکر کن: «داده: TradeGuard — t.me/tradeguard1».
۴) محدودیت نرخ: کش سمت خودت را ۳۰ ثانیه بگذار؛ درخواست پشت‌سرهم لازم نیست.
۵) فید هیچ شناسهٔ کاربر، آیدی چت یا توکنی ندارد و هرگز نخواهد داشت.
