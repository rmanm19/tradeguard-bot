## ⚙️ چطور کار می‌کند (مهم)

GitHub Actions هر جاب را حداکثر ۶ ساعت اجرا می‌کند. این ریپو آن را به یک **زنجیره بی‌پایان** تبدیل می‌کند:

```yaml
concurrency:
  group: tradeguard-bot
  cancel-in-progress: false
```

GitHub در هر گروه همیشه **یک جاب در حال اجرا + یک جاب در نوبت** نگه می‌دارد.
وقتی جاب ۵ ساعت و ۵۰ دقیقه‌ای تمام می‌شود، جابِ در نوبت **بلافاصله** شروع می‌شود.

```
[جاب ۱: 5h50m]──────────────────────────┐
                                        └─► [جاب ۲: 5h50m]──────► ...
                                            ↑ وقفه واقعی: ۳۰ تا ۹۰ ثانیه
```

**آپ‌تایم واقعی: حدود ۹۹.۴٪** — ماهی ۲ تا ۳ ساعت مجموع وقفه، هر بار کمتر از ۲ دقیقه.

### دیتابیس گم نمی‌شود
`tradeguard.db` (کاربران، پرداخت‌ها، اشتراک پرو) در پایان هر جاب:
1. با `db_crypt.py` (HMAC-SHA256، فقط کتابخانه استاندارد) رمزنگاری می‌شود
2. به Actions Cache می‌رود
3. اجرای بعدی برمی‌گرداند و رمزگشایی می‌کند

> ریپو عمومی است و کش برای همه قابل دانلود — **برای همین رمزنگاری اجباری است**. کلید در Secret است، نه در کد.

## 🚀 راه‌اندازی (۱۰ دقیقه، یک‌بار)

### ۱) ریپو بساز
1. [github.com/new](https://github.com/new)
2. Repository name: `tradeguard-bot`
3. **Public** ← **باید عمومی باشد** (دقیقه‌های Actions نامحدود فقط برای ریپوی عمومی است)
4. **Create repository**

### ۲) فایل‌ها را آپلود کن
> ⚠️ پوشه `.github` با نقطه شروع می‌شود — ویندوز آن را نشان می‌دهد ولی بعضی مدیرهای فایل مخفی‌اش می‌کنند.

1. در صفحه ریپو: **uploading an existing file**
2. پوشه `tradeguard-pro` و پوشه `.github` را **با هم Drag & Drop** کن
3. پایین صفحه: **Commit changes**

اگر `.github` آپلود نشد (بعضی مرورگرها پوشه مخفی را رد می‌کنند):
- **Add file → Create new file**
- اسم فایل را تایپ کن: `.github/workflows/bot.yml` ← اسلش‌ها خودشان پوشه می‌سازند
- محتوای فایل را کپی کن → Commit

### ۳) Secretها را بگذار
**Settings → Secrets and variables → Actions → New repository secret**

> ⚠️ **در کادر Name فقط حروف انگلیسی، عدد و `_` مجاز است. فاصله، خط تیره و حروف فارسی خطا می‌دهد.**
> کادر Value هر چیزی می‌تواند داشته باشد (فاصله، `:`، ایموجی…).

**Secretها:**

| Name (دقیقاً همین) | Value | لازم؟ |
|---|---|---|
| `BOT_TOKEN` | توکن BotFather: `123456789:AAH...` | ✅ **اجباری — بدون این هیچ‌کاری نمی‌شود** |
| `ADMIN_USER_ID` | آیدی عددی خودت (از `@userinfobot`) | ✅ **برای پنل `/admin` اجباری** — بدون آن پنل و `/price` و `/broadcast` برای همه قفل است |
| `TG_DB_KEY` | رمز قوی دلخواه | اختیاری |
| `MINI_APP_URL` | لینک مینی‌اپ | اختیاری |
| `PUBLIC_CHANNEL_ID` | `@yourchannel` | اختیاری |
| `SUBSCRIPTION_STARS` | `300` | اختیاری |

**درباره `TG_DB_KEY`:** اگر نگذارش، کلید رمزنگاری دیتابیس خودکار از `BOT_TOKEN` مشتق می‌شود.
یعنی **هیچ کار اضافه‌ای لازم نیست** — فقط `BOT_TOKEN` را بگذار و برو.
(اگر بعداً `BOT_TOKEN` را عوض کنی، دیتابیس قبلی خوانده نمی‌شود؛ در آن صورت `TG_DB_KEY` را صریح بگذار.)

#### ❌ خطای `Secret names can only contain alphanumeric characters…`
یعنی در کادر **Name** یک کاراکتر غیرمجاز گذاشتی. شایع‌ترین‌ها:

| اشتباه | چرا خطا می‌دهد |
|---|---|
| `BOT TOKEN` | فاصله |
| `BOT-TOKEN` | خط تیره |
| `BOT_TOKEN = توکن` | کپی کل جدول راهنما به‌جای فقط اسم |
| `bottoken.` | نقطه |
| `توکن_ربات` | حروف فارسی |
| `123TOKEN` | با عدد شروع شده |
| `BOT_TOKEN ` (فاصله آخر) | فاصله |
| توکن را در کادر Name چسباندی | `:` و طول زیاد |

✅ درست: `BOT_TOKEN` — فقط حروف بزرگ انگلیسی و یک آندرلاین.

### ۴) روشن کن
**Actions → TradeGuard Bot → Run workflow**

بعد از ~۴۰ ثانیه:
```
🛡  نگهبان TradeGuard فعال شد
▶  اجرای bot.py (تلاش #1)
   ✅ متصل شد به ربات: @TradeGuard1_bot
   🌍 ربات آماده است!
```
برو تلگرام و `/start` بزن. ✅

## 🎁 فاز رشد: همه‌چیز رایگان (FREE_MODE)

برای جمع‌کردن ممبر، پرداخت ۳۰۰ استارزی موقتاً بسته شده است:

| چطور | چه می‌شود |
|---|---|
| پیش‌فرض | `FREE_MODE=1` در `bot.yml` → همهٔ کاربران دسترسی کامل دارند (رادار بی‌سقف، هشدارها، مربی AI، فایل MT5/TradingView) |
| خاموش‌کردن فوری | در ربات (فقط مؤسس): `/freemode off` — انتخاب در دیتابیس ذخیره می‌شود و بعد از ری‌استارت هم می‌ماند |
| روشن‌کردن دوباره | `/freemode on` |
| دیدن وضعیت | `/freemode` |
| مینی‌اپ | پرچم `freeMode` در `docs/pro_users.json` منتشر می‌شود؛ کارت خرید پنهان و نشان «🎁 رایگان» جای آن می‌آید |

**مهم:** کد پرداخت حذف نشده؛ صفر تغییر در مسیر Stars لازم است تا دوباره تجاری شود. آمار پرداخت‌ها هم دست‌نخورده در `/stars` می‌ماند (`is_user_pro(..., access=False)`).

### کانال: پست و پین خودکار
| دستور (فقط مؤسس) | کار |
|---|---|
| `/channel @yours` | تنظیم کانال (ربات باید ادمین کانال باشد) |
| `/channelpost` | انتشار فوری پست رادار (۳ فرصت برتر + ترس و طمع + نکتهٔ آموزشی چرخشی) |
| `/channelpin` | ارسال و پین پیام خوش‌آمد با دکمهٔ مینی‌اپ |
| خودکار | هر ۸ ساعت یک پست رادار در کانال |

## 💳 خرید Stars و دعوت دوستان (چطور واقعاً کار می‌کند)

مینی‌اپ **بک‌اند ندارد**؛ پس این دو مسیر عمداً به ربات سپرده شده‌اند و هیچ‌جای مینی‌اپ نمی‌تواند خودش «پرو» بدهد:

| مسیر | چه اتفاقی می‌افتد |
|---|---|
| دکمهٔ «خرید اشتراک» | مینی‌اپ چت ربات را با `?start=pro` باز می‌کند → ربات فاکتور `XTR` می‌فرستد → تأیید تلگرام → `successful_payment` → ۳۰ روز پرو |
| دکمهٔ «کپی/اشتراک لینک دعوت» | لینک واقعی `https://t.me/<bot>?start=ref_<آیدی>` از خود کاربر ساخته می‌شود |
| دعوت دوستان | با استارت شدن لینک، ربات دعوت را ثبت می‌کند؛ ۳ دعوت = ۷ روز پرو (یک‌بار) |
| نمایش پرو در مینی‌اپ | ربات فایل `docs/pro_users.json` را می‌نویسد (کلید = `sha256("tg-pro:"+آیدی)[:16]`)؛ مینی‌اپ همان فایل را می‌خواند |

دستورات مرتبط در ربات: `/buy` (یا `/pro`) · `/invite` · `/status` · `/grantpro <id>` (مخصوص مؤسس).

> ⚠️ پوش این فایل از داخل GitHub Actions انجام می‌شود (`permissions: contents: write` + `PRO_STATUS_PUSH=1`). اگر آن را خاموش کنی، مینی‌اپ همه را «پایه» نشان می‌دهد.

## 🧠 نکات مهم

**۱) پیام‌های زمان وقفه گم نمی‌شوند**
`bot.py` با `offset = 0` شروع می‌کند؛ تلگرام همه آپدیت‌های تأییدنشده را دوباره می‌فرستد. کاربر پیام می‌دهد، ۶۰ ثانیه بعد جواب می‌گیرد.

**۲) دو ربات همزمان نمی‌شوند**
`concurrency` تضمین می‌کند فقط یک جاب پول کند. دو نمونه همزمان = خطای `409 Conflict` در تلگرام.

**۳) اگر ریپو ۶۰ روز بی‌فعالیت بماند**
GitHub زمان‌بندی را خاموش می‌کند. `keepalive.yml` اول هر ماه یک کامیت خالی می‌زند.

**۴) توقف**
**Actions → TradeGuard Bot → ••• → Disable workflow**

**۵) محدودیت صادقانه**
اجرای سرویس دائمی روی Actions یک **منطقه خاکستری در قوانین گیتهاب** است. برای تست، دمو، و شروع کاملاً کار می‌کند. برای **فروش واقعی با مشتری پول‌دهنده**، یک VPS ۵ دلاری (با پرداخت تتر، بدون KYC) حرفه‌ای‌تر و بدون ریسک است — راهنما در `HOSTING_NO_SLEEP_FA.md`.
